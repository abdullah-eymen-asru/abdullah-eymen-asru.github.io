# robots.txt — akademik görünürlük ile veri/gizlilik dengesi
#
# STRATEJİ (özet): "hepsi serbest" ya da "tamamen yasak" yerine hibrit bir
# yaklaşım izleniyor:
#   1) Akademik/içerik alanları (/icerik/, /kurumsal/, kök sayfalar, yazı
#      koleksiyonları) HERKESE (arama motorları + akademik/atıf yapan AI
#      ajanları + genel botlar) AÇIK — amaç bu içeriğin Google Scholar,
#      Perplexity, ChatGPT/Claude gibi araçlarda KAYNAK GÖSTERİLEREK
#      bulunabilmesi.
#   2) Kişisel/dahili alanlar (panel, hesap, önizleme, iç dokümantasyon,
#      worker/veritabanı kaynakları) TÜM botlara (istisnasız) KAPALI — bu
#      dizinler zaten _config.yml'de "noindex, nofollow" meta etiketiyle de
#      korunuyor (bkz. o dosyadaki not); robots.txt burada İKİNCİ bir katman:
#      meta etiketi sayfa İNDİRİLDİKTEN sonra devreye girer, robots.txt ise
#      uyumlu botların sayfayı hiç İNDİRMESİNİ, dolayısıyla dahili yapı
#      hakkında hiçbir bilgi toplamasını engeller.
#   3) Sadece devasa veri kümesi biriktirip atıf/trafik vermeyen toplu
#      EĞİTİM-kazıma botları (ör. CCBot/Common Crawl, GPTBot, ClaudeBot,
#      Google-Extended) site genelinde engelleniyor — bunlar "kaynak
#      göster" davranışı taşımadığından akademik görünürlük hedefine
#      katkısı yok, sadece riski artırıyor. Aynı şirketlerin ARAMA/ATIF
#      amaçlı ayrı botları (ör. OAI-SearchBot, ChatGPT-User, Claude-User)
#      ise bir kullanıcının anlık sorgusuna cevap ararken siteyi ziyaret
#      eder ve genelde KAYNAK GÖSTERİR — bunlara ayrı ve İZİNLİ davranılıyor.
#
# NOT (teknik): robots.txt yolları düz metin/glob (* ve $ joker karakterleri)
# olarak eşleşir; tarayıcı URL encode'u (%20 gibi) burada geçerli DEĞİLDİR.
# Bu yüzden "cloudflare worker" gibi boşluk içeren dizin adları için
# Disallow: /cloudflare*worker/ kullanılıyor — hem düz boşluklu hem de
# herhangi bir ayraçla oluşmuş varyasyonu güvenle yakalar.
#
# NOT: robots.txt TAMAMEN GÖNÜLLÜLÜK ESASINA dayanır — kurallara uymayan
# botları durduramaz (onlara karşı gerçek koruma zaten RLS + auth-guard.js'te
# ve Supabase Row Level Security'de). Burası sadece kurallara uyan/saygılı
# botlara niyeti bildirir.
# ============================================================================
